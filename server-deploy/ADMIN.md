# 自部署服务端管理后台

后台提供「概览 / 音乐源 / 管理员」三个入口。管理接口仅在本机管理端口提供，通过 SSH 隧道访问。

## 首次创建管理员

1. 在自己的电脑建立 SSH 隧道，保持终端打开：

   ```bash
   ssh -N -L 9528:127.0.0.1:9528 user@server.example.com
   ```

2. 在服务器终端生成配对码：

   - Docker Compose：进入部署目录，执行 `sudo ./bin/lune manage`。
   - systemd：执行 `sudo /opt/lune/current/bin/lune-admin-code`。工具需要 Python 3，默认读取 `/etc/lune/lune.env`；可将其他环境文件的绝对路径作为参数传入。

3. 在自己电脑的浏览器打开 `http://127.0.0.1:9528/api/admin/ui`，展开「首次设置 / 忘记密码」，填写服务器刚显示的配对码。
4. 进入「管理员」设置账号与密码，保存后重新登录。后续直接使用账号密码，无需重复配对。

配对码有效期 10 分钟，只能使用一次。管理员账号允许 3–32 位英文字母、数字、下划线、点或连字符；密码为 12–128 位字符。

## 日常使用

- **概览**：查看服务进程、服务端版本、凭据存储和音源账号状态。
- **音乐源**：查看音源账号、最近校验、状态原因和凭据版本；扫码登录、校验或刷新凭据、退出音源账号。
- **启停配置**：保存后需重启服务，界面分别显示当前运行状态和待生效配置，重启前可撤回。默认音源不能直接停用。
- **单曲播放检测**：输入关键词，检查首条搜索结果的歌词和播放地址。取得地址仍需客户端确认实际音频；账号就绪不保证每首歌曲都可播放。
- **管理员**：更新账号或密码，普通登录会话需要输入当前密码；保存后注销全部浏览器管理会话。

服务器地址直接在 Windows 或 Android 客户端填写。后台不提供客户端服务地址编辑或复制功能，业务和管理监听端口仍由部署配置控制。

## 忘记密码

重新执行服务器端的配对码生成命令，从「首次设置 / 忘记密码」进入恢复会话，即可重设管理员账号和密码。不要删除原服务密钥或音源加密凭据。

## 数据、升级与备份

管理员账号保存为 `LUNE_DATA_DIR/admin-account.json`，使用随机盐与 scrypt 保存密码摘要，不保存明文密码；文件以原子替换写入，Linux 新文件权限为 `0600`。

升级时保留完整 `LUNE_DATA_DIR`、原 `LUNE_MASTER_KEY` 和 `JWT_SECRET`。数据目录中的管理员账号、音源凭据和房间均需备份。旧版本没有管理员账号文件时，升级后通过首次配对创建账号。

浏览器管理会话有效期 30 分钟，使用 HttpOnly、SameSite=Strict Cookie；写操作要求同源和 CSRF 校验。重启或修改账号会使管理会话结束，之后使用账号密码重新登录。管理员密码、服务器 SSH 密码和音乐平台账号彼此独立。

systemd 的 `LUNE_CONFIG_FILE` 应位于服务账号可写、允许原子替换的持久目录；新版模板为 `/var/lib/lune/config/providers.json`。旧部署仍使用只读 `/etc/lune/providers.json` 时，按自部署指南迁移后再通过后台保存启停配置。

## 排查音源问题

「账号就绪」表示凭据校验通过；搜索、歌词与播放地址是不同能力。若搜索或歌词正常但无播放地址，请更换关键词检测，并在音乐平台官方 App 核实账号购买、会员和地区权益。不要把单曲不可播误认为管理员登录失败，也不能据此断定整个音乐源不可用。

健康检查只确认服务或账号状态。首次部署、升级或音源重新登录后，仍需用外部客户端验证搜索、实际播放和房间同步。
