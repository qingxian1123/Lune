# Lune 服务端 2.1.0

版本整理日期：2026-10-27。

## 新增

- 黑色扁平管理后台，提供概览、音乐源和管理员三个入口，适配桌面与窄屏。
- 持久管理员账号与密码登录；首次设置和忘记密码通过 10 分钟有效的一次性配对码完成。
- 管理员密码使用随机盐和 scrypt 摘要保存；写入采用原子替换，修改账号后注销全部浏览器管理会话。
- 音源扫码登录、凭据校验与刷新、账号退出、待重启启停配置，以及搜索、歌词和单曲播放地址检测。
- systemd 的 `bin/lune-admin-code` 配对码生成工具，以及随发布包分发的 `ADMIN.md`。

## 调整

- 移除管理后台的客户端服务地址展示和复制功能。服务地址直接在客户端填写，监听地址和端口由部署配置管理。
- 区分音源运行状态与持久配置，支持重启前撤回启停配置。
- 管理端口继续使用本机监听与 SSH 隧道；写操作保留同源、CSRF 和 HttpOnly 会话保护，登录限制失败尝试次数。
- 新建 systemd 部署将 Provider 配置放在 `/var/lib/lune/config/providers.json`，使后台可在受限持久目录中保存配置。
- Node.js 发布包与 Compose 发布附件补齐版本清单、管理说明和本版本发布说明，仅包含当前实际使用的管理页面。

## 升级

1. 备份环境文件、原主密钥、JWT 密钥和完整数据目录；已有管理员需保留 `admin-account.json`。
2. 使用新发行目录或带摘要的新镜像更新，保持单实例；重启后用原管理员账号重新登录。
3. 首次使用管理员账号时，在服务器生成配对码，从「首次设置 / 忘记密码」创建账号，以后直接使用账号密码。
4. 旧 systemd 部署若使用只读 `/etc/lune/providers.json`，按部署指南迁移到可写持久目录后再通过后台启停音源。

音源凭据、房间和 Provider 配置格式保持为 1，无需重置数据。现有客户端协议未调整，客户端与共享包版本保持 2.0.0。

## 验证范围

服务端类型检查、管理页面 JavaScript 语法与静态审查已完成。现场 systemd 实例的管理页面、存活检查和账号就绪检查已有响应；音源就绪不保证单曲播放权限。

Docker 镜像构建、Compose 安装/升级/恢复、浏览器登录与扫码流程以及 Windows/Android 联调仍需目标环境验收。本次版本整理不代表镜像或 GitHub Release 已发布。
