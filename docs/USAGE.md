# 使用说明

## 连接服务与加入房间

首次打开客户端时填写管理员提供的 Lune 服务地址。客户端不提供公共服务器，也不需要用户登录音乐平台；音源账号由服务管理员统一配置。

输入昵称后可以创建房间，或填写朋友提供的六位房间码加入。邀请朋友时分享房间码，并确保大家连接的是同一个服务。

## 一起听歌

搜索歌曲或歌单，将喜欢的内容加入队列。所有成员均可选歌、切换下一首、调整播放进度和维护队列；房主标识不代表独占控制权限。

房间采用无暂停模式。本机静音、系统暂停或耳机断开只影响当前设备，其他成员继续播放。恢复声音后，客户端按房间的最新进度继续。

## 共听记录与收藏

在房间的「选歌 → 我的」中切换共听记录与收藏。记录按日期分组，可搜索歌名、歌手、专辑或房间码；收藏按最近收藏排序。点击「加入」将歌曲加入当前房间的待播队列，不会立即切换正在播放的音乐。

播放页、搜歌结果、歌单歌曲和记录列表中的书签按钮用于收藏或取消收藏；爱心仍用于向房间发送喜欢，不会自动收藏。两者相互独立。

数据仅保存在当前设备或浏览器，按连接的服务器区分，不会跨设备同步。共听记录从使用此功能后开始，记录加入房间时正在播放的歌曲和后续切歌，不代表本机已完整听完，也不会补回离线期间错过的歌曲。拖动进度、维护队列与重连到同一首歌不重复记录。本机所有服务器合计保留最近 500 条记录、最多 1000 首收藏。旧版仅保存歌曲 ID 的收藏数据不删除，但因缺少音源和曲目信息，不会自动合并到新列表。

「清空记录」需再次确认，仅清空当前服务器的共听记录，不影响收藏。若本机存储不可用或空间不足，界面会提示未保存，可在「我的」内重试保存；关闭前请留意此提示。

浏览器不同标签页会同步已保存的变化，但当前本机存储没有跨标签事务：同时修改，或某一页保存失败后重试，仍可能覆盖另一页的更改。首版建议在一个窗口管理记录与收藏。

手动验收建议：在 Windows 和 Android 分别检查空列表、长歌名、日期分组、搜索、超过 50 条后的加载更多；收藏后重启检查保留情况；拖动进度与断线重连检查不重复记录；连续播放同一首歌检查产生新记录；切换服务器检查隔离；断线时检查加入按钮禁用；检查键盘焦点、移动端滚动和系统返回。

## 断线与退出

短暂断线会自动重连，保留当前身份。断线超过默认 30 秒后，成员可能从在线列表消失，但可恢复身份仍然保留；这个时间不代表必须重新加入。

所有人离线后，房间默认保留 24 小时。未过期时可使用原身份恢复；主动退出会撤销当前身份。服务重启后的恢复需要管理员保留数据目录和原签名密钥。

## Android 后台播放

进入房间后，客户端使用前台媒体服务提供通知栏与锁屏媒体卡。媒体卡可操作喜欢、本机静音／恢复、下一首和离开房间。Android 13 及更高版本需要通知权限才能正常显示系统通知。

耳机或蓝牙断开会暂停并锁住本机声音，需明确点击“恢复声音”，避免突然外放。来电或其他应用打断后，如果系统未自行恢复，可使用页面或通知栏中的恢复入口。

不同手机的后台与电池策略会影响持续播放。若锁屏后声音停止，记录机型、系统版本、电池设置和复现时长，按 [播放与连接故障处理](playback-reliability.md) 检查。

## 遇到问题

连接异常与播放异常会分别显示提示。音乐源登录失效应联系服务管理员；只有明确的房间或身份失效才需要重新加入。不要通过不断切歌处理单台设备的播放失败，以免影响其他成员。
