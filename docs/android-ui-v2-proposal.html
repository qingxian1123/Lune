U1封面月光辉光

取色逻辑移除后播放页略显扁平。用静态品牌紫辉光 + 双层投影找回氛围深度——纯 CSS,无 JS 开销,不会随封面跳色。

U2Up-Next 行

曲名下新增「接下来 · ○○」胶囊,数据取 queue[0],点击直达队列面板。共听场景里「下一首是什么」是高频疑问,现在一眼可见。

U3缓冲反馈

之前删掉了文字提示,缓冲状态改用进度条微脉动表达,不占版面、不打断视线。

U4Dock 高亮态

面板打开时对应 Dock 按钮点亮,关闭后还原,强化「当前在哪」的空间感。

U5断线横幅

connected=false 时顶部出现品牌色细条「正在重连…」(见空态屏)。现在断线只有人数文字悄悄变化,用户无感知。

U6空态升级

未播放时不再是灰字占位:月牙插画 + 「去搜索一首歌」CTA 直接拉起搜索面板,把新用户第一步铺到眼前。

U7-U8歌词与队列细节

歌词遮罩渐隐区拉长,滚动进出更柔;队列中下一首加 UP NEXT 徽标,与 U2 呼应。

动效阶段 C 手势

面板下滑关闭手势、播放页↔歌词页淡入过渡、封面按压微缩反馈。需少量 JS(touch 事件),原型未演示。
