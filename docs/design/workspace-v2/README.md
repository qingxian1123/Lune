## 第一版布局与交互

1. 沿用现有静夜黑、柔光象牙、薰衣月光、中文系统字体及低对比细分隔线。新增页面共用同一导航宽度、图标、列表行高和控件规格。
2. 在「设置 → 功能区样式 → 完整工作区」启用。连续主表面覆盖中央舞台，无外边缘 16px 留白、外圆角或外阴影；左侧统一入口为正在播放、搜索音乐、发现歌单、共听热榜、我的音乐、播放队列、房间成员。设置固定在侧栏底部。正在播放收起完整功能区；右上角不重复提供返回或简约切换，功能区样式仍在设置中调整。
3. 浏览页只保留一行搜索与音源选择。歌单封面使用独立正方形区域，标题与作者信息始终位于图片下方。整张卡片是一个可聚焦入口，移除重复的查看按钮和封面操作覆盖层。
4. 详情页以发现歌单面包屑回到原搜索结果并保留搜索条件、来源与滚动位置。封面与标题分列；标题允许换行。只突出全部加入队列，移除重复返回按钮及重复页标题。
5. 歌曲使用统一平面列表，对齐序号、封面、曲名与歌手、专辑、时长。收藏和加入队列使用轻量图标，在悬停及键盘焦点时显现，并保留可读名称与状态。
6. 底部持续播放条使用安静变体，中间显示进度，不重复显示正常连接与正在播放状态；保留本机静音、缓冲与异常反馈。窄于或等于 760px 时进度移至播放条上沿，时间文字隐藏。不加入暂停能力，房间爱心和本机收藏继续维持独立语义。
7. 按用户反馈去掉“几人在房间”“几人一起听”及其状态圆点、搜索结果统计整行，以及侧栏队列与成员旁的数字徽标。搜索后直接呈现内容，移除文字后收拢留白；不以头像组、在线文案或其他徽标替代。常驻侧栏不再显示邀请码；复制邀请码仅保留在成员页。歌曲时长、播放进度与歌单曲目数等内容信息保留。异常与失败反馈仍须在实际出现问题时提供。
