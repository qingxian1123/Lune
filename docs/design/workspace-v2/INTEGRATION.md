# 完整功能区第一版：界面整合交接

日期：2026-10-29

状态：桌面界面已按本文与后续需求接入代码。配色与界面模式已拆开，自定义快捷键已移除。**本文不表示已经完成运行或视觉验收。**

## 已落地的结构

- 界面模式与配色分开：`完整功能` / `观赏播放`，以及 `深色` / `浅色`。模式只在「设置 → 界面模式」切换，不随窗口尺寸或最大化改变。
- 深色与浅色使用同一套语义色。完整功能区是纯灰阶实色；观赏播放使用玻璃材质（`stage-material.css`），不再存在 `frosted` 主题。
- 旧外观迁移：`moonlight`、`frosted` → 深色；`daylight`、`apple-music` → 浅色。旧布局 `workspace` → 完整功能，`compact` → 观赏播放。`libraryOpen` 只决定观赏小面板是否展开。新用户默认完整功能、深色。
- 自定义快捷键的设置、监听、持久化和按钮提示已删除。Tab、Enter、方向键、Esc 关闭浮层和焦点恢复仍然保留。
- 搜索、歌单、音源、我的音乐和滚动位置仍由同一个 `SearchPanel` 持有。模式切换不重建房间控制器或播放连接。

## 已确定的设计原则

- **纯灰阶、克制分层。** 界面底色、文字、图标和交互强调不加入紫色或其他彩色装饰；实际专辑封面仍使用真实图片。通过表面明度而非大面积边框、阴影或强对比块区分区域。
- **视觉优先，去掉解释性副文本。** 不增加装饰性说明、状态口号、重复标题或大块信息条。保留完成操作所需的名称、歌曲/歌手信息、时间、错误和无障碍名称；它们是功能信息，不是装饰性副文本。
- **窗口顶栏简洁。** 完整功能区顶栏文字只保留 Lune；保留原生窗口操作和拖拽能力，不加入房间状态、邀请码、人数或额外标题。
- **延续原播放栏。** 底部继续复用项目的 `TransportBar` 与既有交互、布局和语义，只按主题做必要的表面和图标适配。不要依据参考音乐软件重新设计播放控件，也不要加入暂停能力。
- **导航紧凑。** 左侧标题为「库」，使用小图标与短标签，选中态以浅层底色表达；设置位于侧栏底部。不要恢复左侧大块长条信息卡、常驻邀请码、人数统计或数字徽标。
- **三列优先。** 宽窗口为导航、内容和播放详情；中窄窗口按可用空间折叠播放详情，窄窗口导航收为图标栏。详情面板放封面、当前歌曲、歌词与接下来，内容区按页面呈现搜索、歌单、列表、队列、成员与设置。

## 配色基准

以下是 Figma 色板中的语义色值；同名用途不一定能直接一对一映射现有全局变量，接入时应先确定作用域，避免影响其他页面或主题。色值均为 RGB 三通道相等的中性色。

| 用途 | Graphite 深色 | Light Gray 亮色 |
| --- | --- | --- |
| 主画布 | `#171717` | `#F7F7F7` |
| 侧栏 | `#1E1E1E` | `#EEEEEE` |
| 面板 | `#222222` | `#FFFFFF` |
| 控件 | `#292929` | `#ECECEC` |
| 悬停 | `#323232` | `#E4E4E4` |
| 选中 | `#3C3C3C` | `#D9D9D9` |
| 边界 | `#444444` | `#D0D0D0` |
| 主要文字 | `#E8E8E8` | `#202020` |
| 次级文字 | `#B2B2B2` | `#555555` |
| 弱文字 | `#959595` | `#666666` |
| 强调 / 焦点 | 焦点 `#D4D4D4` | 主要操作 `#292929` |
| 反色操作文字 | `#181818`（用于浅色操作面） | `#F7F7F7`（用于深色操作面） |

Figma 中深色方案的 `#181818` 用在**浅色操作面上的深色文字**，亮色方案的 `#F7F7F7` 用在深色操作面上的浅色文字；不要把同名变量机械地跨主题复制。设计稿没有给每一种交互状态都指定最终色值，悬停、按下、焦点、禁用及错误状态应在现有状态语义上补齐并保持可辨认。普通正文及输入提示文字的目标对比度至少为 4.5:1；色板中主文字与画布、次级文字与面板、弱文字与控件的组合已按不透明色值计算，实际透明度、叠层和状态仍需逐项验证。

## 组件与适配依据

- 复用现有字体栈、图标和组件，参照 [组件状态画板](https://www.figma.com/design/JkOsO0WQZvvLltY9ZOXToE?node-id=26-17) 统一按钮、搜索框、曲目行的默认、悬停、焦点、禁用与选中状态。焦点必须可见，图标按钮保留可访问名称，避免把状态仅交给颜色表达。
- 1600px 样板使用约 214px 导航、324px 播放详情面板、44px 搜索输入和 54px 曲目行；这些是设计参考，不应以固定宽度挤压内容，也不等同于窗口断点。
- 当前样板还包括 1200px 和 760px 窗口。现有代码在工作区容器不超过 1180px 时将播放详情改为可打开的浮层、导航为 180px；不超过 760px 时导航为 64px；不超过 540px 时进一步收拢表格和设置布局。整合时保留真实容器尺寸与可用性，并在边界附近检查，不要仅针对三个固定画板截图硬编码。
- 列表、封面、控件和侧栏的圆角采用小而一致的体系；优先使用现有兼容规格并对照画板，避免为每个页面创造近似但不一致的新数值。长标题、省略、滚动、空态、加载和失败状态仍需保持可用。
