信息架构：三层结构

首页 → 播放页 → 底部面板。桌面版的三栏布局（舞台 + 侧栏 + 传输条）在手机上折叠为单列：播放舞台占满全屏，搜索 / 队列 / 成员改为随叫随到的底部面板（Bottom Sheet），符合 Android 用户的肌肉记忆。

视觉语言：延续桌面版

完整沿用桌面 token：近黑底色 #0B0B0C、月光紫 #B8B0D8、1px 低透明描边、大圆角卡片、衬线斜体小标 + 字距放大的中文小标。首页保留月牙剪影与漂浮粒子，播放页保留封面取色氛围光（原型中以品牌紫示意，实际由 useAccentColor 驱动）。

播放页：单手可达

核心操作全部落在拇指热区：进度条、下一首大按钮（Lune 无暂停，「下一首」就是最重要的动作，做成胶囊主按钮）、收藏、音量。封面与歌词预览区点击即进入歌词全屏。非房主视角下进度条锁定、「下一首」隐藏，文案换成「与房主同步」。

歌词页与手势

歌词全屏保留翻译行与当前行放大高亮，房主可点行跳转。底部迷你条一键回到播放页。系统级手势：底部面板下滑关闭、返回手势逐级退出（歌词 → 播放页 → 确认离开房间）。

后台播放（必须项）

方案：Tauri 原生插件（Kotlin）起前台服务 + MediaSession，WebView 继续跑 WebSocket 同步与 AudioEngine；通知栏/锁屏显示封面、进度与「喜欢 / 下一首 / 离开」。需申请 FOREGROUND_SERVICE_MEDIA_PLAYBACK 权限并处理音频焦点。这是移植中最大的一块原生工作量。

功能对齐清单

创建/加入房间 · 房间码复制分享 · 同步播放（时钟校正）· 多音乐源单曲/歌单搜索 · 歌单整单加入 · 队列增删与长按拖拽排序 · 成员列表 · 歌词+翻译 · 收藏 · 本机音量 · 断线重连提示 — 与桌面版一一对应，无功能裁剪。
